# MyBabyNotes Home Assistant add-ons

Add this repository to Home Assistant (Settings → Add-ons → Add-on Store → ⋮ →
Repositories):

```
https://github.com/straplocked/mybabynotes-hassio-addons
```

The add-on source of truth lives in the
[main MyBabyNotes repository](https://github.com/straplocked/mybabynotes) under
`deploy/ha-addon/`; CI publishes it here on each tagged release. See the
add-on's own [DOCS](mybabynotes/DOCS.md) for local vs remote mode.
